# ⚽ Futbolcu Kim?

Futbolseverler için geliştirilen günlük futbolcu tahmin oyunu.

Oyuncuların özelliklerini karşılaştırarak günün futbolcusunu en fazla 6 tahminde bulmaya çalışırsınız.

## 🎮 Özellikler

- Günlük futbolcu sistemi
- Futbolcu arama
- 6 tahmin hakkı
- 🟢 Doğru özellik
- 🟡 Yakın değer
- 🔴 Yanlış özellik
- İpucu sistemi
- Günlük geri sayım
- Kazanma / kaybetme ekranı
- Tahmin geçmişi
- Kullanıcı kayıt ve giriş sistemi
- JWT Authentication
- Kullanıcıya özel oyun kayıtları

## 🛠️ Teknolojiler

### Backend

- C#
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- ASP.NET Core Identity
- JWT

### Frontend

- HTML
- CSS
- JavaScript

## 🗄️ Veritabanı

Entity Framework Core Code First yaklaşımı kullanılmaktadır.

Temel tablolar:

- Players
- DailyGames
- AspNetUsers
- UserGames
- UserGuesses
